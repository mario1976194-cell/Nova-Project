# Nova3DS

**Nova** is a project exploring how far a **voxel game can be pushed on the original Nintendo 3DS hardware**.

The game features a small procedurally generated voxel world using **Perlin noise**, where the player can freely wander, explore and place blocks.

The main focus of the project is not simply making a voxel game, but testing the limits of what the original 3DS can handle while maintaining a smooth and playable experience.

## Goals

Nova is built around a few main goals:

*  Maintain a stable **30 FPS**
*  Provide **smooth gameplay**
*  Push the limits of the original 3DS hardware
*  Experiment with procedural voxel worlds
*  Explore performance and optimization techniques for constrained hardware

Nova is developed by a **solo developer**.

Because the project is developed independently, **slow updates are to be expected**. Development speed may vary depending on the complexity of new features, optimization work, and the challenges of developing for the original 3DS hardware.

## World

The world is a voxel-based environment generated using **Perlin noise**.

The procedural generation allows the terrain to be created algorithmically while keeping the world within reasonable limits for the target hardware.

## Hardware

Nova specifically targets the **original Nintendo 3DS**.

The project is designed around the limitations of the original hardware, making performance and optimization important parts of development.

The goal is to see just how far a voxel-based game can be taken while keeping the experience smooth and maintaining the **30 FPS target**.

## Installation

The `.3dsx` file is **plug and play**.

No additional assets, resource files, or folders are required. Simply place the `.3dsx` file on your 3DS SD card and launch it through your preferred homebrew launcher.

**No `assets` folder or additional resources are required.**
